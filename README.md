# JMeter CI/CD Automation with Jenkins

## Project Overview
This project demonstrates automating JMeter performance tests using Jenkins CI/CD pipelines.

## Tools & Tech
- JMeter
- Jenkins
- Git
- CI/CD
- HTML/JTL reports

## Steps
1. Clone the repository
2. Open JMeter scripts in JMeter
3. Configure Jenkins pipeline using Jenkinsfile
4. Execute pipeline to run automated performance tests
5. View results in generated HTML reports

## Notes
- Ensure Jenkins has required plugins: Git, Pipeline, CI/CD, Performance Plugin (optional)
